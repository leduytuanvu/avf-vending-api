# Postman scripts

- `generate_collection.sh` — regenerate `postman/collections/` and `postman/environments/` from OpenAPI (`tools/build_postman_collection.py`)
- `check_artifacts.sh` — validate committed Postman JSON (`tools/check_postman_artifacts.py`)

Wrappers at repo root: `scripts/generate_postman_collection.sh`, `scripts/check_postman_artifacts.sh`.
